## 📖 Overview

The Nepal Engineering Council (NEC) requires engineering graduates to pass a nationwide professional licensure examination to register as a professional engineer.

This repository provides exhaustive, high-yield revision notes, theoretical explanations, formula summaries, diagrams, and MCQ preparation content for all **10 major chapters** outlined in the official curriculum (`Electronics,CommunicationandInformationEngineering.pdf`).

---

## 📝 Examination Pattern

| Attribute | Details |
| :--- | :--- |
| **Exam Type** | Objective Multiple Choice Questions (MCQs) |
| **Total Marks** | 100 Marks |
| **Total Questions** | 60 Questions (40 × 1 mark + 20 × 2 marks) |
| **Duration** | 2 Hours |
| **Negative Marking** | None |
| **Sections** | 10 Chapters, each carrying 10% weightage (approx. 10 marks per chapter) |

## 🛠️ Building Textbooks & PDFs

The repository includes a Python automation script (`build_pdf.py`) that parses Markdown files, applies custom academic CSS stylesheets (with print-friendly headers, footers, callout boxes, and formatted formulas), and renders ready-to-print PDFs.

### Prerequisites

Install the required Python packages:

```bash
pip install markdown weasyprint
```

*(Optional fallback: `pip install pdfkit` with `wkhtmltopdf` installed).*

### Generate PDF / HTML

To compile the textbook:

```bash
python build_pdf.py
```

The output will be generated as:
- `NEC_Chapter1_Complete_Textbook.html`
- `NEC_Chapter1_Complete_Textbook.pdf`

## 🎯 How to Use This Material

1. **Self-Study**: Start with each section's introductory concept, followed by formula lists and design methodologies.
2. **Review High-Yield Callouts**: Pay special attention to `> [!NOTE]`, `> [!IMPORTANT]`, and `> [!WARNING]` boxes across the files.
3. **Solve Objective Questions**: Test yourself on key numerical formulas, standard definitions, and circuit/system behaviors.
4. **Offline Printing**: Use the generated PDFs for distraction-free offline study and revision.
